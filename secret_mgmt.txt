Step 1: Create a Kubernetes Secret
kubectl create secret generic my-secret --from-literal=DB_PASSWORD=admin123


Here:
- my-secret – Secret name.
- DB_PASSWORD – Secret key.
- admin123 – Secret value.
Step 2: Check Secrets
kubectl get secrets


Step 3: Describe Secret
kubectl describe secret my-secret


It displays the Secret information and keys, but does not display the actual values.
Step 4: Create a Deployment
Create deployment.yaml:
apiVersion: apps/v1
kind: Deployment

metadata:
  name: secret-deployment

spec:
  replicas: 1

  selector:
    matchLabels:
      app: secret-app

  template:
    metadata:
      labels:
        app: secret-app

    spec:
      containers:
      - name: nginx
        image: nginx

        env:
        - name: DB_PASSWORD
          valueFrom:
            secretKeyRef:
              name: my-secret
              key: DB_PASSWORD


Step 5: Apply Deployment
kubectl apply -f deployment.yaml


Step 6: Check Pods
kubectl get pods


Step 7: Verify Secret inside the container
kubectl exec -it POD_NAME -- printenv DB_PASSWORD


Output:
admin123


Step 8: Delete resources
kubectl delete deployment secret-deployment
kubectl delete secret my-secret
